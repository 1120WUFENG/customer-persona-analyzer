# 💳 信用卡催收回款分析平台

基于客户画像的催收回款分析工具，对接南海区人民法院合作资源，智能匹配最优催收策略。

## 🎯 核心功能

### 回款率预测
基于 10+ 因子综合评估客户回款可能性：
- 房贷资产、联系状态、还款记录、还款金额、逾期时长、套现行为、投诉记录等

### 催收策略匹配（4 大工具）

| 工具 | 适用条件 | 成本 | 周期 |
|------|---------|------|------|
| ⚖️ 人民法院调解平台立案 | 逾期≥3月 + 本金≥5K | 低 | 15-30天 |
| 🏛️ 法院和解中心调解 | 佛山本地 + 态度消极 | 中 | 7-15天 |
| 📞 法院线路电话调解 | 能联系上 + 有调解空间 | 低 | 1-3天 |
| 📜 律所律师函 | 有资产/高额度/重视征信 | 中 | 7-10天 |

### 法诉条件筛选
自动筛选符合条件的客户（逾期≥3月 + 本金≥5000），按优先级排序。

### 催收优先队列
综合逾期金额、回款可能性、时间紧迫度，生成 Top N 催收名单。

## 📊 分析输出

- 智能洞察（法诉匹配、回款预估、失联预警等）
- 催收工具匹配（每人推荐最优工具）
- 法诉筛选（可立案/已立案/即将符合）
- 催收优先队列（Top 30）
- 客户分群画像（含催收策略建议）
- 分步催收方案
