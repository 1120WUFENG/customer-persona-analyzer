# 👤 客户画像快速分析平台

一个纯前端的客户画像分析工具，支持 CSV/JSON 数据导入，自动聚类分析，可视化展示客户分群。

## ✨ 功能特性

- 📥 **多格式导入** — 支持 CSV、JSON 文件拖拽上传
- 🔍 **智能识别** — 自动识别字段（年龄、性别、地域、消费等）
- 🤖 **K-Means 聚类** — 自动将客户分群，生成画像
- 📊 **多维可视化** — 饼图、柱状图、雷达图等多种图表
- 🎯 **画像生成** — 自动生成客户群体画像卡
- 📤 **报告导出** — 一键导出 JSON 格式分析报告
- 🎲 **示例数据** — 内置 200 条示例数据，快速体验

## 🚀 快速开始

直接打开 `index.html` 即可使用，无需后端服务。

```bash
# 或使用本地服务器
npx serve .
python3 -m http.server 8080
```

## 📊 数据格式

### CSV 示例
```csv
id,姓名,年龄,性别,地区,消费金额,活跃天数,订单数,偏好,会员等级
U0001,张三,28,男,北京,15000,20,35,数码,金卡
U0002,李四,35,女,上海,8000,12,18,服饰,银卡
```

### JSON 示例
```json
[
  {
    "id": "U0001",
    "姓名": "张三",
    "年龄": 28,
    "性别": "男",
    "地区": "北京",
    "消费金额": 15000,
    "活跃天数": 20,
    "订单数": 35,
    "偏好": "数码",
    "会员等级": "金卡"
  }
]
```

## 🔬 分析维度

| 维度 | 说明 |
|------|------|
| 年龄分布 | 18-24、25-34、35-44、45-54、55+ |
| 性别比例 | 男/女比例分析 |
| 地域分布 | 按城市/地区统计 |
| 消费水平 | 0-1k、1k-5k、5k-1w、1w-3w、3w+ |
| 活跃频率 | 低频、中频、高频 |
| 偏好标签 | 品类偏好雷达图 |

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + Vanilla JS
- **图表**: Chart.js 4.x
- **CSV解析**: PapaParse 5.x
- **聚类算法**: K-Means（纯 JS 实现）
