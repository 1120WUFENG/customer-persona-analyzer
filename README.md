# 👤 客户画像深度分析平台 v2

纯前端客户画像分析工具，支持 15+ 分析维度、RFM 模型、CLV 计算、流失预警。

## ✨ 核心功能

### 📊 15 个分析维度
| 维度 | 说明 |
|------|------|
| 年龄分布 | 18-24、25-34、35-44、45-54、55+ |
| 性别比例 | 男女比例分析 |
| 地域分布 | 按城市/地区统计 |
| 消费水平 | 6 档消费分层 |
| 活跃频率 | 低频/中频/高频 |
| 偏好标签 | 品类偏好雷达图 |
| 渠道来源 | APP/小程序/PC/线下/第三方 |
| **RFM 分群** | 8 类客户价值分群 |
| **生命周期价值** | CLV 预测 |
| **流失风险** | 多因子流失预警 (0-100) |
| 客单价 | AOV 分布 |
| 退货率 | 退货行为分析 |
| 满意度评分 | 1-5 分评分分布 |
| 忠诚度 | 4 级忠诚度评估 |
| 消费趋势 | 上升/稳定/下降 |

### 🤖 智能分析
- **K-Means 聚类** — 8 维特征自动分群
- **RFM 模型** — 自动评分 + 8 类分群
- **CLV 计算** — 客户生命周期价值预测
- **流失预警** — 多因子风险评分
- **智能洞察** — 自动生成运营建议

### 🎯 画像卡片
每个群体包含：
- 基础画像（年龄/性别/地域）
- 消费特征（消费额/客单价/订单数/复购率）
- 风险指标（流失风险/退货率）
- 价值评估（CLV/忠诚度/RFM分群）
- **运营策略建议**

## 🚀 快速开始

```bash
# 直接打开
open index.html

# 或本地服务器
npx serve .
```

## 📊 数据字段

支持自动识别以下字段：

| 类别 | 字段 |
|------|------|
| 基础 | id、姓名、年龄、性别、地区 |
| 消费 | 消费金额、订单数、客单价、退货率 |
| 行为 | 活跃天数、登录次数、浏览时长、加购数 |
| 时间 | 注册日期、最近活跃、首次购买、最近购买 |
| 其他 | 偏好、渠道、评分、会员等级、优惠券使用 |

## 🛠️ 技术栈

- HTML5 + CSS3 + Vanilla JS
- Chart.js 4.x（15 种图表）
- PapaParse 5.x
- K-Means 聚类（纯 JS）
