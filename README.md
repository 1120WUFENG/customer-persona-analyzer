# 💳 信用卡客户画像分析平台

基于信用卡业务场景的客户画像分析工具，覆盖逾期风险、套现预警、还款行为、投诉分析等核心维度。

## ✨ 业务字段

| 字段 | 说明 |
|------|------|
| 办卡时间 | 信用卡开卡日期 |
| 办卡单位 | 发卡银行/机构 |
| 征信单位 | 近五年征信查询记录 |
| 户籍地址 | 客户户籍所在地 |
| 居住地址 | 客户现居住地 |
| 信用额度 | 银行授信额度 |
| 还款记录 | 正常/偶尔逾期/经常逾期/严重逾期 |
| 消费记录 | 高/中/低/极少消费 |
| 是否进线投诉 | 是否有投诉记录 |
| 逾期天数 | 当前逾期天数 |
| 最后还款时间 | 最近一次还款日期 |
| 还款金额 | 最近还款金额 |
| 是否有房贷 | 房屋贷款情况 |
| 电话沟通记录 | 催收沟通状态 |
| 逾期金额 | 信用卡逾期总额 |
| 是否有套现 | 疑似套现标记 |
| 套现商家名称 | 套现关联商户 |
| 性别 | 客户性别 |
| 年龄 | 客户年龄 |

## 🔬 分析维度（17 项）

### 👤 基础画像
- 年龄分布、性别比例、地域分布、办卡单位、卡龄分布

### 💰 额度与消费
- 信用额度分布、消费记录分类

### ⚠️ 逾期与风险
- 逾期天数分布、逾期金额分布、风险等级

### 💳 还款行为
- 还款记录、还款能力评分、还款意愿评分

### 🔍 风控指标
- 套现记录、投诉记录、电话沟通状态、房贷情况

## 🤖 智能评分模型

| 模型 | 说明 | 权重 |
|------|------|------|
| **风险评分** | 逾期(30) + 逾期金额(20) + 套现(20) + 投诉(10) + 还款记录(10) + 电话(10) | 40% |
| **还款能力** | 额度(25) + 房贷(15) + 还款金额(25) + 消费(20) + 年龄(15) | 30% |
| **还款意愿** | 还款记录(30) + 最近还款(20) + 电话态度(20) + 投诉(15) + 套现(15) | 30% |

## 🎯 客户分群（自动聚类）

- 👑 优质客户 — 低风险、高还款能力与意愿
- 🚀 成长型客户 — 潜力客户，可深度开发
- ⚠️ 风险预警客户 — 需密切关注
- 🚨 高危客户 — 需立即干预
- 🔍 套现嫌疑客户 — 需风控排查
- 😴 沉睡客户 — 需激活唤醒
- 🌱 新客户 — 需培养引导
- 👁️ 特殊关注客户 — 需个案处理
